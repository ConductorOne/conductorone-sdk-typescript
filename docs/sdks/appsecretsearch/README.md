# AppSecretSearch

## Overview

### Available Operations

* [searchMyVendedCredentials](#searchmyvendedcredentials) - Search My Vended Credentials

## searchMyVendedCredentials

Lists credentials C1 issued to the signed-in requester. This is separate
 from the general secret inventory because a connector can discover other
 secret resources on the same account.
