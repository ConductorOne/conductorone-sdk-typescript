# DateField

DateField renders a date picker. The value is an ISO-8601 calendar date
 ("YYYY-MM-DD") stored in the enclosing StringField's string value.

## Example Usage

```typescript
import { DateField } from "conductorone-sdk-typescript/sdk/models/shared";

let value: DateField = {};
```
