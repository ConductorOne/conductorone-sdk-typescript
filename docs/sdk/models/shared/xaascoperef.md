# XAAScopeRef

XAAScopeRef is a lightweight reference to a scope, used for websocket
 notifications and search filter refs.

## Example Usage

```typescript
import { XAAScopeRef } from "conductorone-sdk-typescript/sdk/models/shared";

let value: XAAScopeRef = {};
```
