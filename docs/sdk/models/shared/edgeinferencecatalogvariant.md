# EdgeInferenceCatalogVariant

EdgeInferenceCatalogVariant is one way to reach a provider: a provider profile with its native format,
 destination, credential source and model id grammar.

## Example Usage

```typescript
import { EdgeInferenceCatalogVariant } from "conductorone-sdk-typescript/sdk/models/shared";

let value: EdgeInferenceCatalogVariant = {};
```
