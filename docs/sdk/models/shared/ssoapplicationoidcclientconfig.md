# SSOApplicationOIDCClientConfig

SSOApplicationOIDCClientConfig is the administrator-supplied configuration
 from which C1 mints an App-owned OAuth client. The client ID is never input.

## Example Usage

```typescript
import { SSOApplicationOIDCClientConfig } from "conductorone-sdk-typescript/sdk/models/shared";

let value: SSOApplicationOIDCClientConfig = {
  authentication: {},
  displayName: "Evans_Douglas58",
};
```
