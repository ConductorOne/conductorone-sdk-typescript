# TBVerdictReason

TBVerdictReason is the structured parse of one Time Bandit verdict reason
 string. The raw string is the matching verdict_reasons entry.

## Example Usage

```typescript
import { TBVerdictReason } from "conductorone-sdk-typescript/sdk/models/shared";

let value: TBVerdictReason = {};
```
