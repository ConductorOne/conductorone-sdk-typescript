# TaskTypeAction

The TaskTypeAction message.

This message contains a oneof named target_object. Only a single field of the following list may be set at a time:
  - scopeRole
  - toolCall
  - finding
  - credentialIssue
  - accessProfileComponent


## Example Usage

```typescript
import { TaskTypeAction } from "conductorone-sdk-typescript/sdk/models/shared";

let value: TaskTypeAction = {};
```
