# PersonalSpendRemedyRequestSizing

PersonalSpendRemedyRequestSizing is server-owned guidance for changing the
 caller's personal total after a refusal. It exposes one actionable total and
 never identifies the outer control that may cap or prevent the request.

## Example Usage

```typescript
import { PersonalSpendRemedyRequestSizing } from "conductorone-sdk-typescript/sdk/models/shared";
```
