# EdgeEgressRequestMatch

EdgeEgressRule is one ordered row of an Edge's egress access policy.
 EdgeEgressRequestMatch selects requests by method, path, query and headers. Every set
 selector must match (AND); an unset selector does not constrain. Within a selector,
 methods match any listed value. Each query or header key constrained by a value glob
 must occur exactly once in the request, or the request is denied.

## Example Usage

```typescript
import { EdgeEgressRequestMatch } from "conductorone-sdk-typescript/sdk/models/shared";
```
