# A2UIProvenanceSource

A2UIProvenanceSource is one self-reported source from a reporting component:
 what a chart or table says it was drawn from, and how many rows fed it.

## Example Usage

```typescript
import { A2UIProvenanceSource } from "conductorone-sdk-typescript/sdk/models/shared";

let value: A2UIProvenanceSource = {};
```
