# SessionPolicyServiceSearchPolicyUsersRequest

SessionPolicyServiceSearchPolicyUsersRequest searches the users a policy
 applies to, one page at a time. This read is served from the
 asynchronously-replicated Postgres mirror of the binding store, so a
 just-made assignment may not appear immediately; the user-scoped reads
 (GetEffectiveSessionPolicy, ListUserPolicies) reflect current state.
