# C1EdgeSettings

C1EdgeSettings is the kind-specific configuration block for the tenant's
 WELL_KNOWN_WORKLOAD_PROVIDER_C1_EDGE provider. Empty: the fleet's issuers
 and subjects are installation configuration, never tenant data.

## Example Usage

```typescript
import { C1EdgeSettings } from "conductorone-sdk-typescript/sdk/models/shared";

let value: C1EdgeSettings = {};
```
