# EdgeEgressHostVerdict

EdgeEgressHostVerdict is the rule step's verdict for one host, plus Time
 Bandit's SSRF floor for IP literals. The mode (observe or enforce) and
 content inspection are not part of it.

## Example Usage

```typescript
import { EdgeEgressHostVerdict } from "conductorone-sdk-typescript/sdk/models/shared";

let value: EdgeEgressHostVerdict = {};
```
