# MCPServerHostedConfig

MCPServerHostedConfig configures a hosted MCP server backed by the MCP gateway.

This message contains a oneof named auth_config. Only a single field of the following list may be set at a time:
  - none
  - bearerToken
  - oauth2
  - customHeader
  - googleServiceAccount
  - awsSigv4
  - basicAuth


## Example Usage

```typescript
import { MCPServerHostedConfig } from "conductorone-sdk-typescript/sdk/models/shared";

let value: MCPServerHostedConfig = {};
```
