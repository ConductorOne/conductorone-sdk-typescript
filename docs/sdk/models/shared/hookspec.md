# HookSpec

HookSpec is the instantiable body of a built-in hook inside a template. Rules
 reference it by key via pre_hook_ids/post_hook_ids; instantiation rewrites the
 key to the minted Hook id.

## Example Usage

```typescript
import { HookSpec } from "conductorone-sdk-typescript/sdk/models/shared";

let value: HookSpec = {};
```
