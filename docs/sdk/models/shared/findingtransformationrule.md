# FindingTransformationRule

FindingTransformationRule transforms a finding at processing time, before
 routing runs. Rules fall through: every matching rule applies its transforms
 in ascending evaluation_order; the last rule to write a given field wins.

## Example Usage

```typescript
import { FindingTransformationRule } from "conductorone-sdk-typescript/sdk/models/shared";

let value: FindingTransformationRule = {};
```
