# SSOApplicationSAMLConfig

SSOApplicationSAMLConfig is the SAML-specific sign-in configuration.

## Example Usage

```typescript
import { SSOApplicationSAMLConfig } from "conductorone-sdk-typescript/sdk/models/shared";

let value: SSOApplicationSAMLConfig = {
  acsUrls: [
    "<value 1>",
    "<value 2>",
  ],
  spEntityId: "<id>",
};
```
