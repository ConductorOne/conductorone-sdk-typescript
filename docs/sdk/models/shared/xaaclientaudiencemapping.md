# XAAClientAudienceMapping

XAAClientAudienceMapping maps a client to its identifier at one resource
 server. Never stores credential material.

## Example Usage

```typescript
import { XAAClientAudienceMapping } from "conductorone-sdk-typescript/sdk/models/shared";

let value: XAAClientAudienceMapping = {};
```
