# TenantEmailProvider

TenantEmailProvider is the API representation of the tenant's email provider.

This message contains a oneof named provider. Only a single field of the following list may be set at a time:
  - c1Builtin
  - awsSes
  - sendgrid
  - microsoftGraph
  - googleWorkspace


## Example Usage

```typescript
import { TenantEmailProvider } from "conductorone-sdk-typescript/sdk/models/shared";

let value: TenantEmailProvider = {};
```
