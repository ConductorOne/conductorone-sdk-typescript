# EdgeInferenceDecisionJudge

EdgeInferenceDecisionJudge configures a decision-model judge choosing between the stage's efficient and capable
 tiers.

## Example Usage

```typescript
import { EdgeInferenceDecisionJudge } from "conductorone-sdk-typescript/sdk/models/shared";

let value: EdgeInferenceDecisionJudge = {};
```
