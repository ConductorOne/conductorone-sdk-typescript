# SpendRemedyReview

SpendRemedyReview is returned only by the separately authorized review endpoint.

This message contains a oneof named change. Only a single field of the following list may be set at a time:
  - personalExtension
  - personalResume
  - appIncrease
  - appResume
  - orgIncrease
  - orgUnfreeze

import { SpendRemedyReview } from "conductorone-sdk-typescript/sdk/models/shared";
