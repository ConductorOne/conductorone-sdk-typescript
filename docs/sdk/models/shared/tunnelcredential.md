# TunnelCredential

TunnelCredential is the API view of one OAuth credential within a bridge.
 The plaintext client_secret is only populated on the CreateBridgeCredential
 response.

## Example Usage

```typescript
import { TunnelCredential } from "conductorone-sdk-typescript/sdk/models/shared";

let value: TunnelCredential = {};
```
