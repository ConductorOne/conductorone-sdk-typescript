# XAAScope

XAAScope is a single OAuth scope exposed by a resource server, elevated into
 a governable object bound to its own entitlement.

## Example Usage

```typescript
import { XAAScope } from "conductorone-sdk-typescript/sdk/models/shared";

let value: XAAScope = {};
```
