# ConnectorHostOutdatedEvidence

ConnectorHostOutdatedEvidence lists the outdated active hosts behind a
 CONNECTOR_HOST_OUTDATED finding, refreshed on every re-observation.

## Example Usage

```typescript
import { ConnectorHostOutdatedEvidence } from "conductorone-sdk-typescript/sdk/models/shared";

let value: ConnectorHostOutdatedEvidence = {};
```
