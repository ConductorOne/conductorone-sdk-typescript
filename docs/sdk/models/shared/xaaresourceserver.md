# XAAResourceServer

XAAResourceServer is a third-party authorization server registered as a
 permitted cross-app-access audience for one application.

## Example Usage

```typescript
import { XAAResourceServer } from "conductorone-sdk-typescript/sdk/models/shared";

let value: XAAResourceServer = {};
```
